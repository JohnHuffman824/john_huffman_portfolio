Binary Space Partitioning

Interactive Algorithm Visualization

BSP trees determine rendering order of polygons without a depth buffer. Made famous by Doom (1993), the algorithm recursively partitions space with dividing lines, then traverses the tree back-to-front for correct painter's algorithm rendering. Watch it step-by-step on the Doom logo below.

How It Works

1. Partition

Choose a dividing line and classify every polygon as front, back, or spanning. Spanning polygons are split along the line.

2. Build Tree

Recurse on the front and back sets, creating a binary tree where each node stores a partition line and its coplanar polygons.

3. Traverse

Walk the tree back-to-front from the viewer's position, drawing far polygons first so near ones correctly overlap.
