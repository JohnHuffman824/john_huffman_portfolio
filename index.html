ConstructAI

AI-Powered Construction Design Automation

A platform that generates preliminary, multi-discipline construction design documents by reasoning about all project variables simultaneously. Describe a building in natural language and get a coordinated 3D model (IFC file) with structural, architectural, and HVAC systems integrated from the start — shifting from reactive clash detection to proactive, constraint-aware design generation.

The core concept is the Representative Building Model: a canonical data structure where the same inputs always produce the same deterministic outputs. Every value traces to its source, making the entire pipeline fully auditable.

Key Features

  • Natural language to IFC pipeline
  • 83-variable engineering taxonomy
  • Multi-discipline constraint solving
  • 3D IFC model viewer
  • Streaming cost estimation
  • Floor plan generation
  • Construction document extraction
  • Site intelligence aggregation

Mako Poker

GTO Poker Coaching Assistant

A mobile-first poker coach that speaks plain English and backs every answer with real math. Ask strategy questions in natural language — like “I have AQo on the bubble with 15BB in the cutoff, UTG opens 2.2x, what should I do?” — and get GTO-backed recommendations with explanations of the underlying solver data.

Built on a three-layer architecture: a CFR (Counterfactual Regret Minimization) solver that computes game-theory-optimal strategies, a precomputed range database for fast lookups, and an LLM layer that translates between natural language and solver output.

Key Features

  • Natural language poker queries
  • CFR+ and Deep CFR solvers
  • Precomputed GTO range database
  • Hand evaluation engine
  • Session presets & context
  • Push/fold chart generation
  • Hand history review
  • Neural network training pipeline

Slay the AI

Real-Time Game Overlay Mod for Slay the Spire 2

An AI-powered overlay mod that reads live game state via Harmony patches and displays intelligent card, relic, and strategy recommendations directly in-game. Tier badges grade every card reward (S/A/B/C/D/F), a corner panel tracks your deck archetype and synergies, and a detail dropdown explains the reasoning behind each recommendation.

The core engine scores cards using base tiers adjusted for synergy and anti-synergy factors detected in your current deck. A deck analyzer identifies archetypes and missing pieces, while a strategy advisor generates human-readable assessments. All scoring is deterministic and runs offline — no API calls required for the base experience.

Key Features

  • Live game state reading via reflection
  • S/A/B/C/D/F tier badges on card rewards
  • Deck archetype detection
  • Synergy & anti-synergy scoring
  • In-game corner panel overlay
  • Detail dropdown with strategy notes
  • All 5 STS2 characters supported
  • 94 tests, TDD-driven architecture
